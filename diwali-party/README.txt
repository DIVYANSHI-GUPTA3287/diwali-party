DIWALI PARTY WEBSITE
1. Open index.html in any browser (double-click). Keep the images/ folder next to it.
2. Edit text/colours/stickers: open index.html in a text editor (VS Code / Notepad). Numbered comments explain each part.
3. Replace artwork: swap files inside images/ keeping the same names, or change the src in index.html.
4. Add family photos: put them in photos/ and in the PHOTO WALL section add src, e.g.
   <img src="photos/family1.jpg" alt="Family photo 1">
5. Change date/time: search 'target' in the script at the bottom of index.html.
6. To put it online free: drag this whole folder onto netlify.com/drop or use GitHub Pages.
